# The One-Line Laugh

One original funny line about screen-time guilt: your phone shames you for six hours of use, but two of those hours were just you looking for where you left the phone. An everyday truth with a surprise twist at the end.

## Run it

```sh
node main.ts
```

This writes the line to `entry.txt` inside the output directory (`MAKEFUN_OUTPUT_DIR`, default `out`).
